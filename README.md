A lightweight, open-source Android network monitor.

## Features

- **Live network speed** in the status bar (`KB/s`, `MB/s`)
- **WiFi & mobile data usage** (today / month)
- **Usage history**
- **Built-in speed test**
- **Home screen widgets**
- **Light & dark mode**

## Build

```
git clone https://github.com/M41NUL/NetMonitor.git
cd NetMonitor
./gradlew assembleDebug
```

Or open the project in Android Studio / AndroidIDE and build from there.
